# Birthday-website

A fun birthday webpage built using HTML and CSS.

This project was created while learning from the Scrimba HTML & CSS course and following along with their tutorial project.

## What I Learned
- Flexbox alignment
- CSS hover effects
- Background images & GIFs
- Gradients in CSS
- Custom Google Fonts
- Basic responsive structure

## Features
- Interactive hover GIF effects
- Birthday-themed UI
- Custom styling with CSS
- Animated gift reveal experience

## Tech Stack
- HTML5
- CSS3

## Future Improvements
- Make it fully responsive for mobile
- Add animations/transitions
- Add music or sound effects
- Create custom themes
